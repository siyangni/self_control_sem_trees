## Executive Summary

The **crimeTrajec** R package has been fully developed as a comprehensive, CRAN-publishable tool for group-based trajectory modeling in developmental criminology. This document provides a complete overview of all package components, instructions for finalization, and guidance for publication.

## Package Overview

### Purpose
crimeTrajec implements group-based trajectory modeling (GBTM) for longitudinal crime data, providing open-source alternatives to proprietary software (SAS PROC TRAJ, Mplus). The package enables researchers to:

- Identify distinct developmental trajectories in offending behavior
- Estimate trajectory parameters using EM algorithm
- Select optimal number of groups using multiple criteria (BIC, AIC, cross-validation)
- Incorporate covariates predicting group membership
- Visualize and interpret trajectory patterns

### Key Features
- **Multiple outcome distributions**: Poisson, zero-inflated Poisson, Gaussian, negative binomial
- **Flexible specifications**: Polynomial trajectories of any degree
- **Advanced model selection**: Integrated BIC, AIC, and k-fold cross-validation
- **Rich diagnostics**: Posterior probabilities, convergence checks, fit statistics
- **Publication-ready visualizations**: Trajectory plots with confidence bands
- **Comprehensive documentation**: Help files, vignettes, academic paper

## Component Descriptions

### 1. Core Functions

#### **fitTrajectory()**
- **File**: `R/fitTrajectory.R`
- **Lines**: ~600
- **Purpose**: Fits group-based trajectory models using EM algorithm
- **Key features**:
  - Multiple outcome distributions (Poisson, ZIP, Gaussian, negative binomial)
  - Polynomial trajectories (customizable degree)
  - Group membership and trajectory covariates
  - Multiple random starts for global optimization
  - Comprehensive convergence diagnostics
- **Returns**: S3 object of class `crimeTrajec` with:
  - Trajectory coefficients
  - Group probabilities
  - Posterior probabilities
  - Model fit statistics (log-likelihood, AIC, BIC)
  - Fitted values

#### **selectNumGroups()**
- **File**: `R/selectNumGroups.R`
- **Lines**: ~350
- **Purpose**: Automated model selection comparing different numbers of groups
- **Key features**:
  - BIC and AIC information criteria
  - k-fold cross-validation
  - Parallel processing support
  - Diagnostic plots
- **Returns**: S3 object of class `groupSelection` with:
  - Comparison table across models
  - Recommended number of groups for each criterion
  - All fitted models for inspection

## Statistical Methodology Summary

### Model Framework
Group-based trajectory modeling as finite mixture:

$$P(Y_{i1}, \ldots, Y_{iT_i}) = \sum_{k=1}^{K} \pi_k \prod_{t=1}^{T_i} f(Y_{it} | \lambda_{kit})$$

### Trajectory Specification
Polynomial functions of time:

$$\lambda_{kit} = \beta_{k0} + \beta_{k1} t + \beta_{k2} t^2 + \cdots + \beta_{kD} t^D$$

### Estimation
- EM algorithm for maximum likelihood estimation
- E-step: Compute posterior probabilities
- M-step: Update parameters via weighted regression
- Multiple random starts to avoid local maxima

### Model Selection
- **BIC**: Bayesian Information Criterion (recommended)
- **AIC**: Akaike Information Criterion
- **CVE**: Cross-validation error (k-fold)

### Outcome Distributions Implemented
1. **Poisson**: Count data
2. **Zero-inflated Poisson**: Excess zeros
3. **Gaussian**: Continuous outcomes
4. **Negative binomial**: Overdispersed counts

## Known Limitations

Current version (0.1.0) has the following limitations:

1. **No standard errors**: Point estimates only; bootstrap SE planned for v0.2.0
2. **Missing data**: Listwise deletion only; MI/FIML planned for future
3. **Single outcome**: No multivariate trajectories yet
4. **No multilevel**: Cannot handle nested data structures yet
5. **Computational speed**: Pure R implementation; Rcpp optimization planned

These are documented in NEWS.md and discussed in the paper's Limitations section.
